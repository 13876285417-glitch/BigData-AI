# 大数据与人工智能课程

本仓库用于 **大数据与人工智能** 课程的学习记录、代码与作业提交。

## 目录结构

- `code/` — 课堂与练习代码
- `notes/` — 学习笔记
- `assignments/` — 课程作业

## 环境

- 系统：macOS (Apple Silicon)
- Python 3.12
- Git 2.50
- VS Code

## Git 学习备忘

```bash
git clone <仓库地址>          # 拷贝远程仓库到本地
git add <文件名>              # 把改动加入暂存区
git commit -m "说明"          # 提交暂存区改动到本地
git push                      # 把本地提交推送到远程
```
