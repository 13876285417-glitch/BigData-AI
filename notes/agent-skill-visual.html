① 一张图看懂：Skill 是什么What is a Skill

Skill = 一个文件夹，里面装着一份「怎么做这件事」的说明书（SKILL.md）和可选素材。 官方把它类比成给新员工看的入职指南。来源①②
AI 就像一个刚入职的高材生——聪明、什么都懂一点，但不知道你们部门的活儿该怎么干。 Skill 就是那份「入职指南」：把老师傅的做法写下来交给它，它立刻就变成了这个岗位的熟练工。

② 一个技能包长什么样Anatomy

技能包的标准目录结构：一份必需的核心文件 + 三类可选资源。 来源①③
想象一个工作交接文件夹：SKILL.md 是那张「操作说明」，必须放； scripts/ 是能直接跑的自动化小工具，references/ 是厚厚的历史资料， assets/ 是现成的模板和封面图。后三样有就放着，没有也不影响开工。

③ 核心机制：渐进式加载Progressive Disclosure

官方称之为 渐进式披露（Progressive Disclosure）：像一本组织良好的手册， 先看目录 → 再看章节 → 最后才翻附录。来源①②④
1

先看目录

所有技能的名片都摆在桌上，但只有一行字。AI 扫一眼就知道该不该伸手。

2

再翻章节

确定了要用，才把这份说明书完整读进来，照着步骤执行。

3

最后查附录

遇到具体细节（比如「表格怎么填」），才去翻对应的资料文件。

好比你去图书馆找资料：先看书架上的书脊（第一层），挑中了才抽出来翻目录（第二层）， 真要用到某个数据了才去查具体那一页（第三层）。没人会把整个图书馆搬回家。

④ 完整工作流程How it works

五步闭环：识别触发 → 加载指令 → 照做执行 → 产出交付 → 复盘进化。 来源①②
这跟新闻编辑部的流程其实一模一样：来稿（你说需求）→ 判断派给哪个记者（匹配技能）→ 记者按采访规范去跑（加载照做）→ 交稿（产出交付）→ 编后复盘，把好经验写进采编手册（复盘改进）。

⑤ 关键区分：Skill 不是什么Skill vs Prompt vs MCP

对比项 Skill（技能） 普通提示词 / 角色扮演 MCP / 插件
本质 结构化的「做事标准与步骤」 一次性的对话指令 连接外部工具的能力
能否跨对话复用 ✅ 可以，装在本地长期使用 ❌ 换个对话就没了 ✅ 可以，但属于工具层
AI 会主动调用吗 ✅ 靠 description 自动匹配触发 ❌ 必须你每次手动说 ✅ 由 AI 决定何时调用
能否版本管理 ✅ 就是一个文件夹，可用 Git 管理 ❌ 难以沉淀 ⚠️ 配置可管理，能力在外部
解决什么问题 AI「做事不贴合业务」 临时问一句话 AI「够不到外部系统」
一句话记住：Skill 管「做事的标准和步骤」，插件管「能调用哪些外部工具」。 前者是方法论，后者是工具箱。来源①④

⑥ 一个最小示例Minimal example

一份 SKILL.md 就两段：上半段说「我是谁、什么时候用我」， 下半段说「具体怎么做」。来源①③
就像一篇新闻稿的结构：前面是「标题 + 导语」（一句话说清这是什么、什么场合发）， 后面才是正文（具体怎么展开）。AI 先看导语决定要不要读，觉得相关才翻正文。

⑦ 用好技能的三条纪律Three disciplines

🎯 匹配才触发

  • 技能和需求对得上，才加载
  • 不相关绝不生搬硬套
  • 建议只开当前任务需要的技能

✅ 按指令执行

  • 加载后立即照做
  • 不跳过步骤、不自行发挥
  • 保持流程的一致性

🔁 用过即复盘

  • 发现过时或错误就修正
  • 让技能持续进化不退化
  • 技能是可积累的资产

⑧ 自测 · 5 道题Self-check

Q1. 一个 Agent Skill 中，唯一「必需」的文件是哪个？
✅ 核心是 SKILL.md，它承载名称、触发条件与操作指令；scripts / references / assets 都是可选的增强项。
Q2. 「渐进式披露」的正确加载顺序是？
✅ 三档加载：元信息常驻 → SKILL.md 正文（触发时）→ 打包资源（按需），这样才能把记忆空间的效率最大化。
Q3. references/ 目录的资料主要怎么被使用？
✅ references 的设计目的就是按需加载，避免无关资料长期占用有限的记忆空间。
Q4. 使用某技能时发现它的指令已经过时、会误导任务，正确做法是？
✅ 应当场修正并记录（技能纪律第③条）：绕开问题会让错误反复出现，技能是可进化、可积累的资产。
Q5. Skill 相比「让 AI 每次自由发挥」，最大优势是什么？
✅ 核心价值是标准化沉淀 + 复用 + 共享：把「怎么做专业」固化下来，而不是每次都靠临时发挥。
🎯 若 5 题全对，说明你已经掌握了 Agent Skill 的核心心智模型： 识别触发 → 加载指令 → 照做执行 → 复盘进化。接下来不妨自己动手写一个 Skill 试试。
