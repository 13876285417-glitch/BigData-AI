① 什么是 Agent Skill（一句话）

Agent Skill 是 一段结构化指令 + 可选脚本/资料 组成的"能力单元"。它把人类完成某类任务的专业流程，沉淀为 AI 可以识别触发、立即照做、跨会话复用的标准技能包。

② 一个 Skill 的典型结构

📄 SKILL.md（必需·核心）

  • 技能名 name + 触发条件
  • 一段精炼的操作指令（告诉 Agent 怎么干）
  • 何时用、何时不用、注意事项

📁 scripts/（可选）

  • 可直接执行的可复用脚本
  • 如生成器、爬虫、转换脚本

📎 references/（可选）

  • 参考文档、数据、模板
  • 按需被读取，不占主上下文

④ 为什么重要（核心价值）

🔄 可复用 —— 一次沉淀多次使用 🎯 专业化 —— 内嵌领域最佳实践 📐 标准化 —— 团队共享统一流程 🧠 省上下文 —— 资料按需加载 📈 可进化 —— 用过就反思改良 🚀 提效率 —— 告别每次从零开始

⑤ 一个最小示例（看懂即可）

# skill: 生成课程周报
name: 课程周报生成器
description: 当用户要"生成/写 周报"时使用
trigger: 周报 / report

# 指令（告诉 Agent 怎么做）
1. 汇总本周 notes/ 与 code/ 的改动
2. 生成结构化 HTML 周报
3. 保存到 notes/weekly/ 并用浏览器预览

⑥ 三个关键纪律

🎯 匹配才触发

  • 技能与需求匹配才加载
  • 不相关绝不生搬硬套

✅ 按指令执行

  • 加载后立即照做
  • 不跳过步骤、不自行发挥

🔁 用过即复盘

  • 发现过时/错误就修正
  • 让技能持续进化不退化

⑦ 自我检测 · 5 道题

Q1. 一个 Agent Skill 的"核心必需"文件是哪个？
✅ 核心是 SKILL.md，它承载名称、触发条件与操作指令；scripts/references 均为可选增强。
Q2. references/ 目录的主要作用是什么？
✅ references 的资料是按需读取的，既能提供细节，又不长期占用有限的上下文窗口。
Q3. 判断：一次应同时加载多个技能以追求全能？
✅ 应一次一个：聚焦匹配的技能，避免指令互相冲突、上下文被稀释。
Q4. 使用技能时发现指令有误/过时，正确做法是？
✅ 应当场修正并记录（技能纪律第③条）：防止错误技能反复拖累后续任务，让技能持续进化。
Q5. Skill 相比"让 Agent 每次自由发挥"，最大优势是？
✅ Skill 的核心价值是标准化沉淀 + 复用 + 共享，把"怎么做专业"固化下来，而不是每次靠自由发挥。
🎯 若 5 题全对——你已经掌握 Agent Skill 的核心心智模型：识别触发 → 加载指令 → 照做执行 → 复盘进化。别忘了自己动手写一个 Skill 练练手！
